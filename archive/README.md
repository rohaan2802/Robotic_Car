# Prototype history

The original Wi-Fi SoftAP sketch and Python mapper are in [ap_prototype](ap_prototype/). The sketch in the local source and ZIP matches the GitHub version after line-ending normalization. The ZIP's Python script, map and measurements workbook matched their extracted counterparts byte for byte. Git history preserves the original layout and README.

The [course report](../docs/project_report.pdf) is a separate artifact. It describes a three-robot design and includes an alternate Wi-Fi station/TCP implementation in its appendix. That implementation has a different transport from the GitHub sketch and remains in the report. The maintained source follows the repository's single-car HTTP design.

The saved map, measurement workbook, report and hardware video were retained under descriptive names. The [assignment brief](../docs/assignment_brief.pdf) came from the local folder. The duplicate ZIP supplied no additional file. The original Desktop folder was retained.
